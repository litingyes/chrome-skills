# Product

## Register

brand

## Users

Developers who already use AI coding agents (Cursor, Claude Code, and similar) and need reliable browser automation inside their agent workflows. They land on the site briefly—often alt-tabbing from their IDE—to decide whether chrome-skills fits before installing or starring the repo.

## Product Purpose

Explain what the chrome-skills project is and why its hub-skill architecture matters: one `chrome` skill with composable internal commands (`cdp`, `extract`, `search`, `fetch`) instead of many separate skills cluttering agent context. Success means visitors understand the model, can install via Skills CLI, and are motivated to star the GitHub repo.

## Brand Personality

Clear, restrained, technical confidence. Docs-shaped—not campaign hype. Speaks to practitioners who respect precise architecture explanations and copy-pasteable commands over marketing claims.

Voice: direct, architectural, show-don't-tell.

## Anti-references

- Generic AI/SaaS landing pages (cream backgrounds, eyebrow kickers on every section, identical feature-card grids)
- Editorial-magazine serif aesthetics (italic display headlines, ruled broadsheet columns)
- Cookie-cutter devrel (gradient heroes, big metrics, "10x faster" claims)
- Vite/React boilerplate left as the visual identity

## Design Principles

- **Name the architecture.** chrome-skills is the project; `chrome` is the hub skill visitors install and invoke.
- **Explain before convert.** Hub-skill value prop and command layers come before install commands.
- **One decisive CTA for GitHub.** Star on GitHub lives in the header—prominent, not repeated across every section.
- **Install via Skills CLI.** Primary install path: `npx skills add litingyes/chrome-skills`, then `scripts/setup`.
- **Practice what you preach.** The page itself should feel as precise and uncluttered as the skill design it describes.

## Accessibility & Inclusion

WCAG AA contrast for body and code text. Respect `prefers-reduced-motion`. Semantic headings and landmarks. Copy-pasteable code blocks with clear labels.
